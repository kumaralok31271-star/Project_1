💰 Simple Expense Tracker in C
A lightweight, beginner-friendly console-based personal finance management application written in pure C. Designed specifically for students and developers learning core programming concepts like structures, file handling, and modular functions.

🚀 Features
Add Expenses: Record transactions with a unique ID, name/description, and monetary amount.

View Records: Clean tabular display of all recorded expenses.

File Persistence: Automatically saves and loads your data from a local text file (expenses.txt) so nothing is lost when you close the program.

Interactive Menu: Easy-to-use CLI driven by a while loop and switch-case statement.
